## Components Implemented

### 1. EventType Enum
- STEP_STATUS_CHANGED
- VARIABLE_CHANGED
- RESOURCE_RELEASED
- TIMER_EXPIRED
- EXTERNAL_CMD

### 2. Event Dataclass
- `type: EventType` - The event type
- `data: dict[str, Any]` - Event payload
- `timestamp: datetime` - Auto-generated or custom

### 3. EventBus Class
- `subscribe(event_type, callback)` - Subscribe to events (supports None for wildcard)
- `unsubscribe(event_type, callback)` - Unsubscribe from events
- `async publish(event_type, data)` - Publish events to queue
- `async start()` - Start event processing loop
- `async stop()` - Graceful shutdown (processes remaining events)

### Features
- Supports both sync and async callbacks
- Wildcard subscription (subscribe to all events with None)
- Uses asyncio.Queue for event processing
- Graceful shutdown with timeout
- Exception handling in callbacks (doesn't crash bus)
